# Прототип агента в Langflow

Для проверки гипотезы собрал простенький флоу в Langflow. Код и схемы закину в наш GitHub чуть позже.

## Запуск
1. Поднять Langflow локально (`pip install langflow && langflow run`).
2. Импортировать файл `ai-booking-flow.json`.
3. В узле модели прописать свой API-ключ OpenAI.
4. Т.к. реального бэка у нас пока нет, я поднял mock-сервер на FastAPI и завернул его в Docker. Контейнер просто отдает захардкоженные слоты. URL этого мока прописан в узле API Request в Langflow.

## Что умеет прототип
- Определять дату (парсит "завтра", "в субботу").
- Вызывать ручку поиска слотов.
- Формировать человекочитаемый ответ.
