Заметки для апдейта схемы (architecture.png) в draw.io:

Что меняем:
1. Между "Мобильным приложением" и "API Gateway" добавляем сбоку новый блок: "AI Agent (Orchestrator)".
2. Клиент общается с агентом по WebSocket или REST (чат-интерфейс).
3. Агент ходит во внешний контур (LLM Provider - OpenAI/Claude).
4. Агент стучится в наш API Gateway для вызова ручек Booking Service.

Самое важное: показать стрелками, что агент НЕ лезет напрямую в Booking DB. Работаем строго через существующий API Gateway, это снимает кучу проблем с безопасностью и дублированием бизнес-логики.
